## 1. 这是什么

一个让玩家在《钢铁雄心 4》（HOI4）里亲自 ~~微操~~ 指挥单场战斗的模组，由两部分组成：

- **HOI4 mod「前敌指挥」**：负责在游戏里提供入口（决议），在 `game.log` 输出开始信息，触发外部程序。
- **外部程序（forward-command.exe）**：一个独立的 3D 六角格战棋程序，负责读取 HOI4 的日志与存档，把正在交战的省份还原成战术地图，并把战斗结果注入回战局。玩家可以逐营指挥战斗，战果回写到 HOI4。

一句话原理：**本模组读取游戏存档和日志，只通过游戏自带的控制台把战果回传**，不修改游戏本体、不联网。

## 2. 安装

### 2.1 环境要求

- 正版 HOI4 **1.19.\***（学习版路径与版本不兼容，暂时无法支持）。
- **Windows + Steam**（目前仅此一个平台）。
- 建议**全 DLC**；DLC 不全时部分装备/编制数据可能对不上（遇到欢迎反馈）。
- 目前本 mod **不兼容** 任何改变游戏数据的 mod，同时加载其他 mod 不保证可以正常运行。
- HOI4 必须设置为**文本存档**：`save_as_binary=no`（见 2.2 第 4 步，程序内可一键处理）。
- 获取 zip 压缩包（**GitHub Releases 或 QQ 群文件下载**）

### 2.2 安装步骤 · 渠道 A：本地安装（此渠道请勿订阅 Workshop）

1. 把 zip 解压到任意位置（桌面、D 盘都行，整个文件夹随意搬动）。
2. 双击 `install-mod.bat`（会自动把 mod 装进 HOI4 用户目录，成功/失败都会停屏提示）。
3. 打开 HOI4 启动器，在播放集中启用 **Forward Command**。
4. 存档格式检查：
   - 安装器发现你的设置是二进制存档时会**当场警告**；
   - 运行 `forward-command.exe`，首启会自动打开**设置页**，页面上有存档格式检测和**一键修复按钮**（修复后需**重启 HOI4** 生效，之后存的档才是文本）。
5. 设置页里确认三个路径（HOI4 安装目录 / 存档目录 / game.log）——正常情况下会自动探测好，点**保存**即可。

### 2.3 安装步骤 · 渠道 B：Steam 创意工坊订阅

1. 打开本文开头的「模组订阅链接」，在 Steam 页面订阅本 mod。
2. 获取对应版本的 zip，然后进行 2.2 中除第 2 步外的其余步骤，**不要运行 `install-mod.bat`**。

### 2.4 更新与卸载

- **本地版更新**：解压新 zip 覆盖（或换个目录），再双击一次 `install-mod.bat` 更新 mod。个性化设置在 exe 旁的 `settings.json`，整个文件夹替换时可保留此文件。
- **Workshop 版更新**：mod 由启动器自动推送更新，无需任何操作；但 zip 里的 `forward-command.exe` 程序仍需手动替换。
- **切换渠道**：
  - 本地转 Workshop：先运行 `install-mod.ps1 -Uninstall`，再订阅；
  - Workshop 转本地：先在 Steam 取消订阅，再运行 `install-mod.bat`。
- **卸载**：
  - 若订阅 Workshop，取消订阅并删除本地文件夹即可；
  - 未订阅的用户可运行 `install-mod.ps1 -Uninstall`（PowerShell），并在 HOI4 启动器播放集中移除本 mod。

## 3. 玩法

### 3.1 开始一场战斗

1. 运行 `forward-command.exe`，主菜单点**开始实时监听**（窗口可以关闭——程序会最小化到系统托盘继续监听，不是退出）。
2. 在 HOI4 里打开**决议**栏，找到 **「前敌指挥」** 类目，出现 **「在〔州名〕进入战术战斗」** 决议，点选决议。
3. 打开决议栏后，也可以在地图上寻找决议图标，在想指挥的州点选图标。
4. 战术战斗窗口将自动打开。几种特殊情况：
   - 所选的州当前没有战斗 → 游戏内弹窗「当前州无战斗」，重选即可；
   - 一个州里同时有多场战斗 → 程序里会弹出**战斗选择器**（地图预览，点选要打的那场）；
   - 同一个州当天选过之后，**几个游戏小时内不能再次选它**（游戏机制限制），换个州或等待到下一天。

### 3.2 部署阶段

- 玩家的营一开始都在右侧**战斗序列**（Order of Battle，OOB）窗口里待命：
  - **安排支援连**：师属支援连可以挂载到不同营，使营获得特定加强；
  - **逐营摆放**：点 OOB 行 → 点地图上部署区内的格子，已部署的营也可以通过点击其他位置改变部署；
  - **划区部署**：师标题上的〔部署 N 到区域〕→ 在地图上**左键拖一个矩形**，全师自动摆放；
  - **自动部署**：右侧面板〔自动部署〕，把剩余营全交给 AI 自动完成摆放（手动摆好的不动）；
  - **召回**：点击〔全部召回〕或师标题〔召回 N 个营〕，将完成部署的营收回OOB。
- 全部营就位后，右侧面板〔**开始战斗**〕亮起，点击后正式开始战斗。

### 3.3 战斗操作

回合制：**1 回合 = 10 分钟，6 回合 = 1 战略小时**。

- **选择**：左键点自己的营（点空地/敌人取消选择）。
- **移动**：右键点目的地，将显示路径带和预计回合数。
- **攻击**：右键点可见敌人，如果临近就是**突击**；直射单位（坦克/反坦克炮等）隔格就是**直射**；炮兵则是**精确射击**。
- **径向按钮**（选中营后浮现，没有的按钮不出现）：
  - **H 坚守**：步兵类进入掩护姿态（防御 +25%），消耗一回合；
  - **E / L 架设·收炮**：牵引类火炮**必须架设才能开火**，收炮才能移动，各消耗一回合；
  - **F 火力任务**：炮兵区域覆盖射击（每回合一次）；
  - **R 撤退**：与敌邻接时边战边撤（以降低组织度为代价）。
- **取消命令**：右键点本营撤销命令。
- **师级命令**：选中师 **指挥部 (HQ)** → 上方按钮条——**推进**（全师发起攻势）/ **占领**（选一个格子占领并守住）/ **歼敌**（追猎一个敌营）。师 AI 代管全师，**后续玩家可以手动操作覆盖师给营下达的命令**。
- **视角**：WASD/方向键平移，滚轮缩放，Q/E 旋转，R/F 俯仰，中键拖地图。
- **结束回合**：右侧面板〔**结束回合**〕→ 你的移动命令先执行，然后敌方 AI 行动。

### 3.4 战报与胜利条件

- 地图上高亮的区域（城市/要地）是目标：攻占全部区域或歼灭敌军即获胜；
- 每场战斗结束自动弹出战报；**每条战报旁的「细节」按钮**可以看到这次交火的完整计算公式。
- 战斗日志窗口（右侧〔战斗日志〕）里，交战行同样可点开显示战斗细节。

### 3.5 同步（Sync）

- 每打完 6 回合（1 战略小时），右侧面板〔**同步到 HOI4**〕亮起：点它把本小时的战果写回 HOI4，**游戏时间随之推进 1 小时**，然后继续打。
  - 战术推演期间，**交战州在 HOI4 里是冻结的**（州上挂着「战术推演进行中」修正），不会重复结算伤害；世界其他地方照常运转。
- 战斗结束后点〔**应用并退出**〕：最终战果写回 HOI4，窗口关闭，游戏内弹窗「战术战斗结束」。
- 中途想停：Esc → 退出游戏（有未同步战果会先询问）；或用同步结算弹窗里的〔**结束战术战斗**〕（已同步的部分保留）。
- **自救通道**：如果程序卡死/崩溃/窗口异常，在 HOI4 决议里点 **「强制退出战术模式」**——立即清理战场状态（未同步的战果丢失）。

### 3.6 战果回写机制（重要说明）

- 默认模式 **回写（组织度+强度，精确到地块）**：防守方的损失精确落到被攻地块；攻方按来源省回写，同省未参战的师可能被轻微波及——这是 HOI4 的命令机制限制，无法指定某一个师收到伤害。
- 不想要任何影响：设置页把「战损回写」改为**不回写**（沙盒模式，打着玩）。

## 4. 设置项说明

主菜单 → 设置：

- **路径 + 语言**：自动探测；语言切换立即生效（中/EN）。
- **战损回写**：是否回写战损，详见 3.6。
- **MSAA 抗锯齿 / 阴影 / 渲染比例 / 帧率上限 / 菜单帧率 / 空闲降帧**：性能相关。
  - 卡顿首先降**渲染比例**（100→85→70→50，牺牲画质获得性能提升）；
  - 其次阴影降到「低/关」、MSAA 降到「2×/关」；
  - 建议选择空闲降帧，战斗窗口不操作时降到约 10 fps（为 HOI4 让显卡），有操作时立刻恢复。
- **导出诊断包**：报 bug 专用，一键打包日志+存档成一个 zip（在 exe 旁），发给群主即可。包内含你机器的路径和存档，介意可先打开看看。
- **关于**：版本号与构建日期等，包括**免责声明**入口。
- 战斗中可改渲染设置：Esc → 设置，渲染项即时生效。

## 5. 已知限制（内测期间）

- 仅 Windows；仅单人；**铁人模式不可用**（需要文本存档）；**多人游戏禁用**。
- 装备/编制等数据可能错位（欢迎反馈具体师编制，建议带存档）。
- 同一个州每天能进入战术战斗的次数受游戏机制限制（见 3.1）。
- 程序通过**模拟键盘**向 HOI4 控制台输入指令：杀毒软件可能拦截或报警（见 FAQ）。

## 6. 反馈与常见问题（FAQ）

**Q：报 bug 要提供什么？**
A：① bug 的详细描述，包括遇到 bug 前后的操作和预期情况；②设置页**导出诊断包**（勾选附带存档）；③有录屏最好。发给群主即可。

**Q：杀毒软件报警/拦截？**
A：程序需要模拟键盘向 HOI4 控制台输入指令（这是战果回写的唯一通道），属于杀软敏感行为。本程序**不联网、无遥测、源码即将公开**（内测群可获得链接），请放心加白名单：
Windows Defender：设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护 →「病毒和威胁防护」设置-管理设置 → 排除项 → 添加文件夹（选你解压的整个目录）。

**Q：游戏卡顿？**
A：先降渲染比例（设置页），再降阴影/MSAA；最后打开空闲降帧。建议使用独立显卡，推荐显存不低于8GB。

**Q：同步后 HOI4 没反应/弹「同步未确认」？**
A：确认 HOI4 还在前台运行、没有停在主菜单、没有暂停（游戏设置里 `pause_on_lost_focus` 建议为 no，否则切窗时游戏不走时间）。按弹窗提示重试或取消即可，已注入的伤害不会丢。

**Q：为什么我读不了我的存档？**
A：必须是文本存档。设置页检测那一行是绿的才行；刚改完 `save_as_binary=no` 之后，要重启 HOI4 并**重新保存一次**新档。

**Q：能打赏支持吗？**
A：可以，完全自愿，点击文末许愿池链接进行打赏。打赏与否不影响任何模组内容、更新和反馈处理。
